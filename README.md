## Pitch angle
"The shop worth the drive." Customers drive an hour each way; cheapest honest maintenance
around (no price gouging); Tommy (owner) personally makes mishaps right; Kayla at the counter;
they've fixed everything from motor homes to Jeeps. Team framing — no owner-shrine section.

## Design
- **Fonts:** Federo (display) + Magra (body) — Google Fonts.
- **Palette — "Zephyr / west wind":** breezy cerulean sky-blue `#2E86C7` + deep marine ink
  `#0E2A3D` + warm wind-gold accent `#E0A02E`, on a pale sky-tinted base `#EAF3FA`. Light,
  airy, coastal-morning feel — distinct from every other demo in the registry.
- Single self-contained `index.html`, inline CSS + minimal JS. Works from `file://` and with
  JS disabled. IntersectionObserver fade-ins respect `prefers-reduced-motion`.
- Sticky header click-to-call (fully visible at 390px); brand name wraps ≤560px. **No** fixed
  bottom call bar. Mobile overflow guardrails in place.
